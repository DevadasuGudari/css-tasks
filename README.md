# CSS Tasks

A collection of small CSS practice tasks. Each task has an `.html` file and a `.css` file.

## Tasks

| No | Task | What it covers | Files |
| -- | ---- | -------------- | ----- |
| 1 | Pseudo Classes | `:hover`, `:focus`, `:first-child`, `:nth-child` | `pseudo-class.html`, `pseudo-class.css` |
| 2 | Scroll | scrollbar, `overflow`, smooth scroll | `scroll.html`, `scroll.css` |
| 3 | Selectors | tag, class, id, group, descendant | `selectors.html`, `selectors.css` |
| 4 | 3D Cube | `transform`, `perspective`, rotate animation | `cube.html`, `cube.css` |
| 5 | Flag | shapes and colors using CSS | `flag.html`, `flag.css` |
| 6 | Chess Board | CSS Grid layout | `chess.html`, `chess.css` |
| 7 | Super Mario | pixel art and CSS shapes | `mario.html`, `mario.css` |
| 8 | Tooltip | text popup on hover | `tooltip.html`, `tooltip.css` |
| 9 | Traffic Lights | colors with animation | `traffic.html`, `traffic.css` |
| 10 | Half Moon | `border-radius` and `box-shadow` | `halfmoon.html`, `halfmoon.css` |

(Change the file names if yours are different.)

## How to Run

1. Keep the `.html` and `.css` files of a task in the same folder.
2. Open the `.html` file with Live Server or in the browser.
